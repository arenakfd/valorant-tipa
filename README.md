# 暗区突围 国际服 (UAGame) 辅助 · 地图.tipa

在 **Superman 工程本体上**改的：工程形态、KFD 内核读写层、ImGui/Metal 渲染底座、
app + HUD 双进程结构、伪装 / 过直播、签名配置 **全都没动**，重写的只有暗区国际服的
功能层和菜单。

> **本版是精简版**：只保留五个功能，其余功能（热成像、无后坐力、自瞄、血条、射线、
> 玩家名、头甲、武器）连同代码和菜单开关一起**全部移除**。先把这五个做扎实，再加新东西。

---

## 一、怎么编

### 方式 A：Xcode 直接编（推荐）

打开 `地图.xcodeproj` → 选 Release → 编 → Xcode 会自动跑工程里的 `Build.sh`
（ldid 签名 → 压 `地图.tipa`），产物在编译输出目录里。

> `Build.sh` 里 ldid 路径写的是 `/opt/homebrew/bin/ldid`，本机没装先 `brew install ldid`。

### 方式 B：命令行 / CI

```bash
./build_tipa.sh        # → 地图.tipa
```

推 main 分支会自动跑 GitHub Actions（macos-14 + Xcode 15），产物在 Actions 那次的
Artifacts 里。

### 装

TrollStore 打开 → 把 `地图.tipa` 丢进去 → 桌面显示成「地图」→
打开 → 主页开功能 → 进游戏看框和骨骼。

## 二、功能（每项独立开关，只有这五个）

主页开关改的是配置 `/var/mobile/Library/Preferences/com.map.settings.plist`，
改完立刻生效，不用重启进程。

| 开关 | 作用 |
|---|---|
| 方框透视 | 敌人方框（真人红 / 人机绿） |
| 骨骼透视 | 方框内骨骼连线 + 头点 |
| 人机显示 | 关掉就只画真人，人机一个不画 |
| 显示距离 | 框正下方居中 `[ xx m ]` |
| 直播隐藏 | 过直播窗口（HUD 内容不进录屏/直播，原工程功能） |

### 绘制布局

```
          ┌────────┐
          │ 方框+骨骼│
          └────────┘
           [ 87 m ]            ← 框正下方居中
```

屏顶居中显示 `真人 X   人机 Y`；队友不画（遍历线程就过滤掉了）；死透的人不画。

## 三、偏移来源

全部对着 **MobileDumper-7 的 dump** 逐条核过（`OffsetsInfo` / `ClassesInfo` /
`StructsInfo` / `EnumsInfo` / idmap），没有一个数是估的。

换算关系：`dump 地址 = 0x100000000 + 相对主镜像(__TEXT)偏移`，代码里存的是相对偏移，
运行时地址 = `UAGame` 模块基址 + 相对偏移（基址每次启动都变，不能写死）。

### 本版在用的关键项

| 用途 | 位置 | 说明 |
|---|---|---|
| 真人 / 人机 | `ASGCharacter + 0x1679` | `EECharacterType`，1=PMC 2=SCAV 是真人，3 起是人机 |
| 角色去重 | `ASGCharacter + 0x1680` | gid |
| 骨骼世界矩阵 | 网格 `+0x890` | `CachedWorldToLocalTransform`，求逆用 |
| 骨骼组件空间坐标 | `USkeletalMeshComponent + 0x9B8` | `CachedComponentSpaceTransforms` |
| 血量（判死亡） | ASC `+0x170` → AttributeSet `+0x44/0x48` | 只读，不画血条 |
| 相机 POV | 相机管理器 `+0x420` / `+0x1F70` | 两个缓存按时间戳取新的 |

## 四、几个坑（都处理了，改的时候别踩回去）

1. **骨骼世界矩阵取错整列**（老工程就有）
   局部→世界的乘法 Y/Z 两行系数取错，等于整列错位一位 → 骨骼随目标朝向乱变、框跟着飞。
   已按 UE4 约定修正。

2. **网格变换两条候选，运行期现场判定**
   `ComponentToWorld` 是 UE4 私有成员、反射导不出来，版本间会飘。
   所以先用 dump 确证有的 `+0x890` 矩阵求逆，再用"网格原点必须贴着角色根位置"当场判定，
   两条都不成立就不用骨骼（走位置框兜底，保证一定有框）。

3. **骨架点位表两套**
   角色是 UE4 人形骨架，但导入时可能被吃掉根骨骼、索引整体挪一位。所以备两套点位，
   按"头必须在骨盆上方"打分自动挑，选一次就锁定，不来回抖。

4. **悬浮球必须单独开窗口**
   HUD 主窗口是触摸穿透的（不然游戏点不动），所以悬浮球和控制菜单各自放进一个
   "只有那么大"的窗口里 —— 能收触摸，其余区域照样穿透。

5. **不调游戏内 UFunction**
   读任何数据都走内存，跨线程调 UE 的函数（exec 桩）容易把游戏搞崩。

## 五、改工程要注意

源文件清单硬编码在 `地图.xcodeproj/project.pbxproj` 里，**加/删文件必须同步改工程文件**
（几百个 UUID 手改必错，建议在 Xcode 里加）。CI 里有个 `tools/check_pbxproj.py`，
编之前先查工程文件结构（少个分号 Xcode 只会说"工程已损坏"，看不出错在哪）。

本地纯 C++ 语法自检：`python3 tools/stub_check.py`（把游戏层头文件放进桩环境编一遍，
把语法错误挡在推 CI 之前）。

版本绑死：游戏一更新（不是 1.0.249 了），整张偏移表要重新 dump 重算。
