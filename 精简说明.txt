 精简版说明 —— 只保留五个功能
═══════════════════════════════════════════════════════════════

一句话：这一版是在你发来的"有效果的那版"源码上直接改的，
        把功能砍到只剩五个，App 里的开关也只留这五个。

───────────────────────────────────────────────────────────────
一、留下的功能（就这五个）
───────────────────────────────────────────────────────────────

  1. 方框透视      敌人方框（真人红 / 人机绿）
  2. 骨骼透视      方框内骨骼连线 + 头点
  3. 人机显示      关掉 = 只画真人，人机一个不画
  4. 显示距离      框正下方居中 [ xx m ]
  5. 直播隐藏      过直播窗口（HUD 不进录屏 / 直播）

  注：屏顶居中那行「真人 X   人机 Y」保留；队友不画；
      死透的人不画（这两个是遍历/过滤逻辑，不是功能开关）。

───────────────────────────────────────────────────────────────
二、删掉的东西（代码 + 开关一起删干净）
───────────────────────────────────────────────────────────────

  功能层：
    · 头戴热成像 T7（含组件定位、真戴判定、框上标注）
    · 无后坐力（含后坐力组件定位、配置写入、hook 那一套）
    · 自瞄 + 自瞄只打真人（含写视角、视角平滑跟随）
    · 显示血量（框左侧竖血条）
    · 射线显示（屏幕顶端到目标的竖线）
    · 显示名字（框上玩家名 / 队伍号）
    · 显示头甲（头盔 / 护甲等级）
    · 显示武器（手持武器名）

  菜单层（App 主界面）：
    · 开关列表从 14 项 → 5 项
    · 「已启用」计数按 5 项统计
    · 环境管理卡片（那个「环境已经隐藏」按钮 + 说明）一并移除
    · 没用的 UI 类（功能按钮）也删了

  模块层（整个目录删掉）：
    · HUD/绘制/游戏/三角洲行动/（另一套游戏的 SDK，本工程用不到）
    · HUD/绘制/游戏/网页雷达/（网页雷达服务器，已下线）
    · 雷达地图/（网页雷达那套网页资源）
    · 工程文件（project.pbxproj）里对应的 14 处引用同步清掉

  说明：伪装 / 环境隐藏 没动（那是让进程能在越狱环境里跑起来的基础，不是功能开关）；
        过直播窗口保留（就是"直播隐藏"这个功能本体）。

───────────────────────────────────────────────────────────────
三、改动的文件
───────────────────────────────────────────────────────────────

  按钮存储.h / 按钮存储.mm
      密钥只留六个：绘图（主开关）/ 方框 / 骨骼 / 人机 / 距离 / 过直播。
      全局设置结构体同步精简。

  应用/应用.mm
      开关列表 → 方框透视、骨骼透视、人机显示、显示距离、直播隐藏。
      总功能数改 5；已启用计数按这 5 项算；环境管理卡片移除。

  HUD/绘制/HUD控制器.mm
      去掉网页雷达的 import 和相关残留。

  HUD/绘制/游戏/暗区突围/国际服/主线程.h
      整段重写：只留 方框 / 骨骼 / 距离 三块绘制 + 骨架自选逻辑。
      相机与投影这一段**一个字没动**（你验证过有效果的就是它）。

  HUD/绘制/游戏/暗区突围/国际服/子线程.h
      删掉装备读取整段（护甲管理器扫描、头盔/护甲/武器名、T7 真戴判定）
      和自身功能组件定位（热成像 / 武器 / 后坐力）整段。
      保留：对象表自适应、名字池自检、类查找、角色遍历、
            真人/人机判定、骨骼数组、血量、队伍过滤。

  HUD/绘制/游戏/暗区突围/国际服/SDK.h
      删掉只给已移除功能用的偏移（热成像链、武器/后坐力链、
      物品与护甲、自瞄的 ControlRotation、队伍组件、物品图标信息）。
      保留在用的：角色类型判定、gid、骨骼矩阵、血量、相机、遍历链。

  HUD/绘制/游戏/暗区突围/国际服/游戏类型.h
      玩家数据结构去掉头甲/武器/热成像/玩家名等字段；
      自身数据结构去掉功能指针与控制器。

五、上手看这几处
───────────────────────────────────────────────────────────────

  1. TrollStore 装 地图.tipa → 桌面「地图」→ 打开 → 把五个开关拨开。
  2. 进游戏：框有没有、骨骼跟人像不像、距离数字合不合眼。
  3. 人机显示关掉，看看是不是只剩真人。
  4. 直播隐藏开着，录屏看一眼 HUD 有没有进去。

  这五个稳住了再说加功能的事。
